# Kubernetes Security Briefing — 13 August 2026

## 🔴 Critical

### 1. Copy Fail — Kernel Page-Cache Container Escape (CVE-2026-31431)

A critical Linux kernel vulnerability in the page-cache Copy-on-Write path allows an unprivileged process running inside a container to corrupt shared file data in-memory without writing to disk. Triggered via an AF_ALG splice race, the exploit enables full container-to-host escape, granting root-level code execution on the node. Validated on Amazon EKS, Google GKE, Alibaba Cloud ACK, and Talos Linux. While many distributions have patched their kernels, multi-tenant Kubernetes clusters sharing images across containers remain exposed until all nodes are updated.

### 2. Dirty Frag — Linux Kernel Container Breakout Chain (CVE-2026-43284 / CVE-2026-43500)

Known as "Dirty Frag," this dual-vulnerability chain combines two independent page-cache write primitives — one in the xfrm-ESP (IPsec) subsystem and another in the RxRPC subsystem — to achieve local privilege escalation from unprivileged user to root. Because Kubernetes workloads share the host kernel, any compromised container on a node running an unpatched kernel can break out. GKE nodes and EKS nodes without Seccomp profiles are particularly vulnerable. Both CVE-2026-43284 and CVE-2026-43500 should be patched immediately across all clusters.

### 3. Fragnesia — Linux Kernel Container Breakout (CVE-2026-46300)

Discovered after researchers identified that patches for earlier kernel exploits were incomplete, Fragnesia (CVE-2026-46300) allows an unprivileged local attacker to escalate privileges to root within a container and then escape to the host system. This affects all GKE versions prior to 2-gke.1346000. Any Kubernetes deployment using Container-Optimized OS or standard Linux kernel images must be verified against this advisory.

### 4. Prowler Kubernetes Provider OS Command Injection (CVE-2026-73263)

CVSS 9.9. Prowler, a widely used cloud security assessment platform, contains a critical OS command injection vulnerability in its Kubernetes provider connection test. Prior to version 5.36.0, the tool accepted `kubeconfig_content` containing a base64-encoded Kubernetes configuration and passed it unsafely to shell commands, enabling arbitrary command execution on the host running Prowler. Attackers who can inject Kubernetes configuration data into Prowler scans gain full control over the scanning infrastructure. Upgrade to Prowler 5.36.0 or later immediately.

### 5. Red Hat Advanced Cluster Management Hub Authorization Bypass (CVE-2026-72526)

CVSS 9.9. A critical authorization-bypass flaw in the `multicloud-integrations` component of Red Hat Advanced Cluster Management for Kubernetes 2 allows any tenant with Application creation permissions to forge the `ocm-managed-cluster` annotation during application propagation. This lets the tenant push arbitrary manifests directly to managed clusters, effectively bypassing all RBAC controls and gaining full administrative access to every downstream cluster. Affected: RHACM 2.x prior to the latest security update.

### 6. Red Hat Multicluster Engine ClusterCurator Privilege Escalation (CVE-2026-73268)

CVSS 9.8. Published less than 12 hours ago. A critical privilege escalation in the `cluster-curator-controller` component of Red Hat Multicluster Engine for Kubernetes allows a tenant with create or update permissions on a ClusterCurator custom resource to escalate to cluster-admin. This enables unauthorized management of entire multi-cluster fleets. Upgrade to the latest MCE release urgently.

### 7. Kuadrant MaaS API Authentication Bypass (CVE-2026-14450)

Any pod running inside a Kubernetes cluster can bypass the Kuadrant AuthPolicy gateway entirely by forging MaaS API requests when Kuadrant is deployed with the default MaaS authentication backend. No credentials or valid tokens are required — the attack leverages the internal service mesh between pods. All environments using Kuadrant with AuthPolicy gateways must reconfigure the MaaS integration to use external identity providers or apply network policies restricting Pod-to-MaaS-API traffic.

### 8. Azure Kubernetes Service Elevation of Privilege (CVE-2026-50516)

CVSS 9.4. A critical elevation-of-privilege vulnerability in Azure Kubernetes Service permits unauthorized privilege escalation without requiring authentication for a critical internal operation. Any actor with access to the Azure virtual network hosting the AKS cluster can leverage this flaw to gain cluster-admin level access. Microsoft has released patches; affected AKS clusters should be upgraded immediately. Microsoft also assigned EPSS risk score indicating active exploitation potential.

### 9. Rancher Cross-Cluster Impersonation Flaw (CVE-2026-44945)

CVSS 9.1. An authenticated user on the Rancher management plane can impersonate any role across any downstream Kubernetes cluster managed by Rancher. By manipulating the cross-cluster impersonation mechanism, an attacker with low-privileged access gains cluster-admin privileges on all managed clusters simultaneously. This affects the Rancher control plane and every Kubernetes cluster under its management. Upgrade Rancher to the latest patch release and audit all downstream cluster RBAC bindings.

## 🟡 High

### 1. containerd CRI Plugin Label Injection (CVE-2026-53488)

CVSS 8.3. The Container Runtime Interface (CRI) plugin in containerd (affects versions prior to 1.7.33, 2.0.10, 2.1.9, and 2.3.2) propagates Dockerfile `LABEL` instructions from image configurations to running containers without sanitization. An attacker controlling container image metadata can inject arbitrary labels that alter host-side behavior, enabling cache poisoning, metric manipulation, and misdirection of monitoring systems. Affected runtime deployments include GKE, EKS, and any cluster using unpatched containerd. Upgrade to patched containerd versions immediately.

### 2. OpenShift AI Training Operator Privilege Escalation (CVE-2026-18951)

CVSS 8.8. The Red Hat OpenShift AI (RHOAI) overlay for the training operator incorrectly aggregates `trainjobs` across namespaces due to flawed label handling. A user with edit permissions in a single namespace can manipulate training job definitions to execute arbitrary code with elevated privileges across the entire OpenShift cluster. All RHOAI deployments should upgrade to patched images released in RHSA-2026:53262 and RHSA-2026:53263.

### 3. ingress-nginx Configuration Injection (CVE-2026-4342)

Comment-based nginx configuration injection discovered in ingress-nginx allows an attacker combining specific Ingress annotations to inject arbitrary nginx directives into the controller configuration. This bypasses the intended annotation sandbox and can lead to configuration-based attacks including header injection and upstream manipulation. Note: ingress-nginx reached end-of-life in March 2026. Migration to Envoy Gateway or maintained alternatives is strongly recommended.

### 4. containerd Memory Exhaustion via Crafted Image (CVE-2026-47262)

CVSS 6.5. A crafted container image can trigger uncontrolled memory consumption within the containerd process, resulting in an out-of-memory (OOM) termination of the container runtime. This denial-of-service attack can cause widespread pod failures across all nodes sharing the same containerd instance. All containerd deployments should be updated to patched versions.

### 5. RHACM Application Subscription Controller Escalation (CVE-2026-10090)

CVSS 7.7. A user holding namespace-scoped "edit" privileges in a Red Hat Advanced Cluster Management hub namespace can create subscriptions that propagate privileged resources to managed clusters. This transforms routine developer access into cluster-wide admin control, affecting all downstream clusters subscribed to the compromised hub. Mitigate by restricting edit permissions in ACM hub namespaces and reviewing existing subscription objects.

### 6. RHACM Channel Operator Vulnerability (CVE-2026-73122)

CVSS 7.7. A flaw in the `multicloud-operators-channel` component of RHACM allows a compromised agent within a managed cluster to reach back to the hub and modify channel configurations. This bidirectional escalation vector lets attackers pivot from a single workload compromise to cluster fleet-wide control. Patch the multicloud-operators-channel component to the latest available release.

### 7. OpenShift Console Dev Console Webhook SSRF (CVE-2026-50236)

CVSS 7.4. An authenticated server-side request forgery vulnerability in the OpenShift Console Dev Console webhook helpers allows attackers to supply target URLs that are fetched server-side by the console backend. This can be leveraged to access internal services, scrape metadata endpoints, and interact with cluster-internal APIs that should not be reachable from the web console. Upgrade OpenShift Console to the patched version released on 11 August 2026.

### 8. DirtyClone — Linux Kernel LPE Variant (CVE-2026-43503)

A follow-up vulnerability to the Dirty Frag chain, DirtyClone exploits a missing flag in spliced UDP packet handling, allowing another path to local privilege escalation from unprivileged container processes to root on the host node. Clusters running kernels between the Dirty Frag patches and the DirtyClone fix remain doubly exposed. Apply the most recent kernel updates.

### 9. containerd Attach Goroutine Leak — Host Memory Exhaustion (CVE-2026-50195)

CVSS 6.5. The containerd CRI server exposes a goroutine leak through the Attach endpoint. An attacker sending rapid attach/detach sequences can exhaust host memory, causing crashes across all containers on the affected node. Update containerd to patched releases.

### 10. containerd Image Layer Denial of Service (CVE-2026-53492)

A vulnerability in the image pulling logic allows a maliciously crafted OCI/Docker image manifest to consume excessive memory during layer extraction, crashing the containerd process. Combined with CVE-2026-47262, this doubles the image-based DoS surface on containerd deployments. Update all cluster runtimes.

## 🟢 Medium

### 1. CSI Driver NFS Path Traversal (CVE-2026-3864)

The Kubernetes CSI driver for NFS contains a path traversal vulnerability via the `subDir` parameter. An attacker mounting a volume with crafted subDir values can navigate outside the intended mount point and delete unintended directories on the NFS server. Clusters using csi-driver-nfs should restrict subDir inputs and audit mounted volumes for lateral filesystem access.

### 2. CSI Driver SMB Path Traversal (CVE-2026-3865)

The Kubernetes CSI driver for SMB shares a similar path traversal vulnerability through the `subDir` parameter, potentially deleting unintended directories on the SMB server. Apply vendor-supplied patches to the SMB CSI driver and review storage class configurations for overly permissive subDir parameters.

### 3. containerd Numeric User Bypasses runAsNonRoot (CVE-2026-46680)

CVSS 6.5. In containerd versions prior to 1.7.32, 2.0.9, 2.2.4, and 2.3.1, containers launched with a numeric `User` field in the OCI spec are allowed to start as UID 0 even when the Pod specifies `runAsNonRoot: true`. This bypasses a fundamental Kubernetes security control relied upon by many production clusters. Patch containerd and verify Pod Security Standards enforcement remains effective.
