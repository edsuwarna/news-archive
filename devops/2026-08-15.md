## 9. 🐳 Docker "CopyEscape" Vulnerability (CVE-2026-17106) — Container-to-Host File Write [Link](https://www.imperva.com/blog/copyescape-taking-over-docker-hosts-with-docker-cp/)

Imperva Red Team disclosed CVE-2026-17106, dubbed "CopyEscape," a critical container-to-host arbitrary file-write vulnerability in Docker's `docker cp` command and `sbx cp`. An attacker-controlled container could exploit a filesystem race condition and symlink tricking to overwrite files outside the intended destination on the host system — potentially gaining full host compromise. Docker addressed this flaw in the 4.86.0 Desktop release on August 10, 2026. Teams should also check the related privilege escalation vulnerability CVE-2026-18171 in Docker Sandboxes.

**Source:** [CopyEscape: Taking Over Docker Hosts with docker cp - Imperva](https://www.imperva.com/blog/copyescape-taking-over-docker-hosts-with-docker-cp/)

## 10. 🕸️ SCTPhantom (CVE-2026-64564) — 18-Year-Old Linux Kernel Flaw Enables Container Escape [Link](https://matrix.tencent.com/en/2026/08/06/sctphantom-CVE-2026-64564)

Tencent Zhuque Research uncovered CVE-2026-64564, an 18-year-old use-after-free flaw in Linux's SCTP ASCONF transport code dating back to 2008. Dubbed "SCTPhantom," the vulnerability allows local users to escalate privileges and escape containers to gain root on the underlying host. Tencent researchers demonstrated successful escapes in 6 of 8 test scenarios. Public proof-of-concept exploits have already been released, making immediate kernel patching critical. Debian 13 has already pushed a security update addressing the flaw.

**Source:** [SCTPhantom: 18-Year-Old Linux SCTP Flaw - Tencent Matrix](https://matrix.tencent.com/en/2026/08/06/sctphantom-CVE-2026-64564)
