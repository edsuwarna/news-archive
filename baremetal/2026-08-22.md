# Top Bare-Metal News — August 22, 2026

## 1. 🟡 Proxmox VE 9.2 Launches Official ARM64 Support for Bare Metal Servers
On August 5, Proxmox Server Solutions announced the first officially supported Arm64 edition of Proxmox Virtual Environment — a long-demanded milestone for users running Arm-based bare-metal hardware. The release brings full feature parity with the x86_64 edition, including QEMU/KVM virtualization, LXC containers, Ceph storage integration, and clustering support. This opens the door to energy-efficient, high-density virtualization use cases on Arm server platforms such as Ampere Altra and AWS Graviton-equivalent silicon. ISO and package repository downloads are available immediately.
