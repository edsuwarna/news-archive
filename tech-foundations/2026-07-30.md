## ☕ Eclipse Foundation
### 🔥 Eclipse Foundation and OWASP Join Forces to Strengthen Open Source Security and CRA Readiness
The Eclipse Foundation and OWASP announced a partnership to help open source projects prepare for the European Cyber Resilience Act (CRA). The collaboration will provide vulnerability disclosure frameworks, security assessment tools, and compliance guidance for the Eclipse ecosystem, marking a critical step in operationalizing CRA requirements for millions of software components.
**Source:** <https://www.eclipse.org/org/press-release/>

### 🚀 Eclipse Foundation and ORC Working Group Launch ORC Learning Hub
The Open Regulatory Compliance (ORC) Working Group at Eclipse launched the ORC Learning Hub, a centralized resource helping maintainers and organizations navigate the CRA's requirements. The platform offers training modules, compliance checklists, and open source tools for regulatory readiness.
**Source:** <https://www.eclipse.org/org/press-release/>

## 🤖 PyTorch Foundation (Linux Foundation)
### 🚀 PyTorch 2.13.0 Release: FlexAttention on Apple Silicon, CuTeDSL Backend, and Major Memory Optimizations
PyTorch 2.13.0 shipped with landmark features: FlexAttention lands on Apple Silicon (MPS) with up to 12x speedup over SDPA on sparse patterns; CuTeDSL "Native DSL" backend gives Inductor a second high-performance code path alongside Triton; and the new nn.LinearCrossEntropyLoss prototype cuts peak GPU memory by up to 4x for large-vocabulary LM training. The release also includes torchcomms — a new communications backend for large-cluster distributed training — and FSDP2 overlap optimizations for increased throughput.
**Source:** <https://pytorch.org/blog/> | <https://github.com/pytorch/pytorch/releases/tag/v2.13.0>
