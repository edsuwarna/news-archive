## 🌐 CNCF (Cloud Native Computing Foundation)

### 1. 📦 Cloud Native Buildpacks Graduates from CNCF Incubator

The CNCF announced the graduation of Cloud Native Buildpacks, an open source toolkit that turns application source code into OCI-compliant container images without Dockerfiles. Originally created by VMware and later donated to Pivotal before joining CNCF in October 2018, Buildpacks moved through Sandbox and Incubating stages before achieving full graduation status. The project enables consistent, reproducible container builds across teams and environments, centralizing base image management and eliminating per-service Dockerfile maintenance overhead. It now operates under a graduated governance model managed by the Buildpacks Technical Oversight Committee.

## 🪶 Apache Software Foundation

### 5. 🌊 Apache Fluss Graduates to Top-Level Project — Streaming Storage for Real-Time Lakehouse

The Apache Software Foundation announced that Apache Fluss has graduated from the Incubator to become a Top-Level Project. Fluss is an open source, lakehouse-native streaming storage system designed for real-time analytics and AI workloads. It provides unified table APIs and low-latency streaming access, bridging the gap between batch data lakes and stream processing. Fluss integrates with compute engines including Apache Flink and Apache Spark, and with open lakehouse formats including Apache Paimon and Apache Iceberg. The project was contributed by Alibaba and entered the Apache Incubator in June 2025, graduating in just one year — notably faster than most incubation timelines.

**Source:** [ASF Announcement](https://news.apache.org/foundation/entry/the-apache-software-foundation-announces-new-top-level-projects-5)

### 6. 📬 Apache Pony Mail Becomes Newest Top-Level Project

Also graduating alongside Fluss, Apache Pony Mail is a high-performance, privacy-respecting mailing list manager for open source communities. It replaces legacy email list software with modern web-based archiving, threading, and moderation tools while preserving email-delivery semantics. Pony Mail serves dozens of large ASF and external open source projects managing millions of messages monthly. Its graduation ensures long-term community stewardship independent of any single vendor or organization.

**Source:** [ASF Announcement](https://news.apache.org/foundation/entry/the-apache-software-foundation-announces-new-top-level-projects-5)

### 8. 📊 Linux Foundation Launches the Tokenomics Foundation to Define AI Economics and ROI Standards

On August 4, 2026, the Linux Foundation formally established the Tokenomics Foundation, backed by more than 30 founding organizations. The new foundation aims to create vendor-neutral open standards, benchmarks, and best practices for measuring AI token economics, total cost of ownership, return on investment, and business value tracking. PointFive joined as a Premier Member on the same day and took a seat on the governing board. The launch responds to industry-wide challenges around rising API costs, unpredictable token pricing, and the lack of standardized metrics for evaluating AI spend effectiveness. The foundation plans to publish reference architectures, measurement frameworks, and cross-provider comparison tools in Q4 2026.
